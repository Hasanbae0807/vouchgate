# VouchGate

Accountability layer for **AgentVouch** — the on-chain endorsement graph for Binance
Agent ID holders on BNB Chain — built for the **Concordium Trusted Agents Hackathon**
(Encode Club × Concordium).

AgentVouch's operator service registers in the Concordium testnet CIS-8004 agent
registry and carries a "Verified by Concordium" badge (CIS-8004 token), so anyone
dealing with the service can check that an identity-verified operator stands behind it.
